# Security Policy

This repository is a public profile and portfolio README linking to projects maintained in their respective repositories. It does not contain an application runtime, API, account system, or deployment secrets.

## Safe handling

- Do not add credentials, private contact details, confidential client information, or personal records to the profile README.
- Keep project security and vulnerability reports in the relevant source repository, using its private reporting channel where available.
- Verify project status and ownership claims before adding portfolio links; a link in this profile is not a security or production-readiness endorsement.
- Treat any credential accidentally committed here as exposed and rotate it with the issuing provider.

## Reporting

For an issue specific to this profile repository, report it privately through GitHub's private vulnerability reporting feature when available. For a linked project's vulnerability, contact that project's maintainers privately.
